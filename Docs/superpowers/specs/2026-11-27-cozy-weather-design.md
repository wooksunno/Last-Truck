# COZY 날씨·낮밤 시험 적용 설계 (KYI_TEST)

작성: 2026-11-27 · 상태: 승인 대기

## 왜
지금 날씨와 낮/밤은 우리 코드(AtmosphereController, DayNightController, WeatherDirector)가 직접 만든다.
COZY 3(이미 `Packages/com.distantlands.cozy.core`에 있음, 3.6.23)로 **화면 연출을 통째로 바꿔 보고**, 지금 방식보다 나은지 직접 보고 비교하려는 시험이다.

## 목표
- KYI_TEST 씬에서 하늘·구름·해·달·빛·안개·비·번개·날씨 소리를 COZY가 그린다.
- COZY 화면이 **우리 게임 흐름을 그대로 따라간다**: 낮 → 노을 → 밤 → 동틀녘, 일차별 날씨, 날씨 키트(F5~F9).
- 플레이 중 **한 키로 COZY ↔ 기존 방식**을 바꿔 가며 같은 장소·같은 시간에서 비교할 수 있다.
- 바꾼 뒤에도 KYI_TEST가 60fps를 유지하고, 성능 차이(GPU %, 전력)를 측정해 함께 보고한다.

## 하지 않는 것
- MiningMapTest/Menu 씬, 빌드 씬 목록은 건드리지 않는다.
- 게임 규칙(GameManager 낮 길이·밤 판정, 생존 조건, 날씨 패널티, 날씨 결정 규칙, 멀티플레이 코드)은 바꾸지 않는다.
- 기존 날씨/낮밤 코드를 지우지 않는다 (끄기만 한다).
- 눈·계절·COZY 무작위 예보는 쓰지 않는다.

## 실패로 볼 것 (돌아가도)
- COZY를 끄면 원래 화면으로 완전히 돌아오지 않는다.
- COZY 시계가 따로 흘러서 게임은 낮인데 화면은 밤인 식으로 어긋난다.
- 플레이어마다 날씨가 다르게 보일 수 있는 구조가 된다.

## 방식 (고른 것: A)
| | 방식 | 장단점 | 결과 |
|---|---|---|---|
| A | COZY = 화면 연출 전부, 우리 코드 = 언제·무슨 날씨 | 규칙·멀티 그대로, 켜고 끄며 비교 가능 / 연결 스크립트 필요, COZY에 없는 우리 기능 일부 빠짐 | **선택** |
| B | COZY가 시계·예보까지 결정, 게임이 COZY를 따라감 | COZY 기능 전부 / 게임 규칙·멀티 코드 수정, 게임 전체 영향 | 시험 목적에 너무 큼 |
| C | COZY만 놓고 손으로 시간·날씨 바꿔 보기 | 가장 빠름 / 실제 게임 흐름과 맞물린 모습은 못 봄 | 제외 |

## 설계
### 1. 씬 구성 (KYI_TEST만)
- `Resources/Cozy Prefabs/Cozy Weather Sphere` 프리팹은 씬에 미리 넣지 않고, **플레이가 시작되면 연결 스크립트가 만들어 DontDestroyOnLoad로 옮긴다** (설계 중 변경).
  이유: COZY는 에디터에서도 실행되며 씬의 조명 설정(RenderSettings)을 바꿔 씬에 저장해 버리고, 씬에 있으면 우리 WorldChunkCuller가
  COZY 하늘·비를 고정 물체로 등록해 멀어지면 숨길 수 있다. 런타임에 만들면 둘 다 피하고, 씬 변경도 연결 오브젝트 하나로 줄어든다.
  COZY의 `Tools/Cozy/Setup Scene` 메뉴는 **기존 방향광(해·달)을 지우겠냐고 묻고 지우므로 쓰지 않는다**.
- 새 컴포넌트 `CozyWeatherBridge`(Assets/LastTruck/Scripts/)를 같은 씬에 둔다. 이 컴포넌트가 있는 씬에서만 연결이 동작한다 (FrameRateLimiter와 같은 방식).
- 씬 작업 전 KYI_TEST 백업을 스크래치패드에 만든다.

### 2. 켜고 끄기 (비교용)
- `CozyWeatherBridge`의 체크박스 `useCozy`(기본 켬)와, 플레이 중 **F12**로 바로 바꾼다 (F10·F11은 능력 디버그 창이 사용). F12는 날씨 키트(F4~F9)처럼 개발 빌드(에디터 포함)에서만 동작한다.
- COZY 켬:
  - COZY 오브젝트 활성화, COZY 시계 정지(`perennialProfile.pauseTime`), 날씨 선택 방식 `manual`.
  - 우리 쪽 끔: AtmosphereController, DayNightController, 그들이 쓰는 해·달 방향광, 밤 포스트 프로세싱 Volume, WeatherDirector의 비 파티클,
    PastelLook(화면 톤 Volume + 우리 SoftCloud 구름 — COZY 구름과 겹치므로. 이미 F2 켜기/끄기 기능이 있으니 그것을 쓴다).
  - 낮 포스트 프로세싱 Volume은 **켜 둔다** (날씨/낮밤이 아니라 게임 기본 색감이므로). — 설계자 판단
  - WeatherDirector의 비 파티클은 WeatherDirector 안에서 만들어지므로, WeatherDirector에 "화면 연출 끄기" 정적 값 하나를 추가해
    켜져 있으면 비 파티클과 안개 값 전달만 건너뛴다. 날씨 결정·패널티·알림은 그대로 동작한다. (공용 코드 수정은 이 한 곳뿐)
  - 우리 셰이더 전역값: `_GameWeatherFog = 0` (안개는 COZY가 그린다), `_GameNightFactor`는 연결 스크립트가 계속 채운다 (아래 3).
- COZY 끔: COZY 오브젝트 비활성화, 위에서 끈 것을 전부 원래 상태로 되돌린다. 끄기 전에 바꾼 RenderSettings(주변광 모드/색, 반사 설정, 기본 안개)는 켤 때 저장해 두고 끌 때 복원한다.

### 3. 시간 연결 (우리 → COZY)
- AtmosphereController와 같은 방식으로 "밤 정도"(0 낮 ~ 1 밤)를 계산한다: `GameManager.DuskProgress`를 따라 올라가고, 밤이 끝나면 `dawnSeconds`(10초)에 걸쳐 내려온다.
- COZY 시각으로 바꾸는 규칙 (끊기지 않고 앞으로만 흐르게):
  - 해질녘 전 낮: 낮 경과 비율에 따라 08:00 → 16:30
  - 해질녘(밤 정도 0→1): 16:30 → 20:00 (COZY 노을이 이 구간에 나오게)
  - 밤: 20:00 → 02:00 사이를 천천히 흐른다 (밤 길이는 생존 조건에 따라 달라서, 시간이 아니라 "밤이 얼마나 지났는지"로 천천히 움직이고 02:00에서 멈춘다)
  - 동틀녘(밤 정도 1→0): 05:00 → 08:00 (02:00 → 05:00은 건너뛴다. 동틀녘 10초에 맞춰 바로 새벽으로)
- `_GameNightFactor`(캐릭터·월드 셰이더 밤 표현, PastelLook)는 이 밤 정도 값으로 계속 채운다. 그래야 COZY 빛과 우리 셰이더가 같은 밤을 표현한다.

### 4. 날씨 연결 (우리 → COZY)
- `WeatherDirector.Kind`(일차 규칙 + 날씨 키트 결과)를 그대로 따른다. 결정 규칙·패널티는 손대지 않는다.

  | 우리 날씨 | COZY 날씨 프로필 |
  |---|---|
  | 맑음 | Mostly Clear |
  | 짙은 안개 | Dense Fog |
  | 비 | Light Rain |
  | 폭풍우 | Thunder Storm (번개·천둥 포함) |
- 바뀔 때 `CozyEcosystem.SetWeather(프로필, 전환시간)`을 부르며, 전환 시간은 지금과 비슷하게 약 6초.
- 날씨 소리는 COZY 프로필에 들어 있는 것(빗소리·천둥)을 그대로 쓴다. 우리 BGM은 그대로 둔다.
- 멀티플레이: 각 화면이 이미 동기화된 GameManager/WeatherDirector 값을 COZY에 넣으므로 모두 같은 하늘·날씨가 된다. 이번 시험에서는 싱글플레이만 확인한다.

### 5. 이번 시험에서 빠지는 우리 기능 (COZY에 없음)
- 동굴 안 어두워짐, 밤 화면 효과(푸른 톤·강한 블룸·비네트), 랜턴으로 안개 걷기.
  시험 결과를 보고 COZY를 계속 쓰기로 하면 그때 다시 붙인다. 날씨 패널티 문구의 "랜턴으로 안개가 걷혀요"는 COZY 켠 동안 실제와 맞지 않는다.

## 성공 기준 (확인 방법)
1. 컴파일 성공, 플레이 중 콘솔 에러 없음.
2. KYI_TEST 플레이: COZY 하늘이 낮 → 노을 → 밤 → 동틀녘을 게임 진행대로 따라간다 (밤을 강제로 만들어 확인, 시점별 스크린샷).
3. 일차 날씨와 F5~F8로 고른 날씨가 COZY 프로필로 바뀐다 (각 날씨 스크린샷).
4. F12로 COZY ↔ 기존 방식이 바뀌고, 끄면 기존 화면이 원래대로 돌아온다 (같은 위치 전후 스크린샷).
5. 60fps 유지. COZY 켬/끔 GPU %·전력·온도를 비교해 보고한다.
6. 다른 씬(Menu 등)은 플레이해도 COZY·연결 스크립트 영향이 없다.

## 만드는 사람에게 맡기는 것
- COZY 모듈 중 실제로 붙일 것(시간·날씨·대기·환경음 등)과 프로필 세부 값.
- 시간 연결 곡선의 정확한 모양 (위 구간과 "끊기지 않고 앞으로만" 조건만 지키면 된다).
- 끄고 켤 오브젝트를 찾는 방법 (씬 참조 연결 또는 자동 검색).
- 밤 동안 "얼마나 지났는지"는 연결 스크립트가 밤 시작부터 직접 잰다 (GameManager에 공개된 밤 경과 값이 없음).

## 설계자 판단으로 정한 것 (검토 부탁)
- 비교 전환 키: F12 (개발 빌드·에디터만, 구현 중 F10 충돌로 변경).
- 낮 Volume은 유지, 밤 Volume·PastelLook은 COZY 켬 동안 끔.
- 날씨 소리는 COZY 프로필의 빗소리·천둥을 그대로 사용.
- 날씨 매핑: 맑음 = Mostly Clear(구름 조금), 비 = Light Rain(폭우 아님).

## 추가 (2026-11-27): 날씨 연출은 COZY로 통합, 눈 추가
사용자 결정: 날씨 **연출만** COZY로 (결정 규칙·패널티·멀티 동기화는 우리 WeatherDirector). 밤 기본은 ② (COZY 밤 + 우리 셰이더 밤 값), 낮은 ① (낮 Volume 끔).

눈(WeatherKind.Snow) — 값은 설계자 제안, 사용자 수정 가능:
- 나오는 곳: **COZY 연결이 있는 씬(KYI_TEST)에서만**. CozyWeatherBridge가 `WeatherDirector.SnowAvailable`을 켠다.
  COZY가 없는 씬(MiningMapTest)은 눈 연출이 없어서 눈 날씨가 나오지 않는다 (기존 날씨 표 그대로).
- 확률: 3일차부터, 낮 12% · 밤 18% (기존 규칙과 다른 별도 주사위 — 눈이 안 나오는 날은 기존 날씨 그대로).
- 패널티: 이동 -10%, 트럭 -15%. 옅은 안개 0.3(비와 같음: 좀비가 12% 가까이서 나타남). 5초에 걸쳐 서서히.
- COZY 프리셋: `Legacy/Heavy Snow.asset` (항상 눈). Light Snow는 게임 카메라 거리에서 눈송이가 거의 안 보여서 구현 중 Heavy로 변경 (Inspector snowProfile로 바꿀 수 있음).
- 날씨 키트: "눈" 버튼, 단축키 Shift+F7. 눈을 쓸 수 없는 씬에서는 고르지 않고 안내만 띄운다.
- 하지 않는 것: 땅에 눈 쌓임(COZY Interactions 모듈 + 우리 셰이더 수정 필요), MiningMapTest 적용.

## 추가 (2026-11-27): COZY 켬 동안 빠졌던 기능 다시 붙이기 (A 조합)
코드: `CozyWeatherBridge.Lighting.cs`, `CozyWeatherBridge.Ambience.cs` (부분 클래스). COZY는 매 프레임 조명을 다시 쓰므로,
렌더 직전(beginContextRendering)에 COZY 공개 값(주변광 색·안개 농도)으로 최종 값을 매번 새로 계산한다(값이 쌓이지 않게).
- 밤 밝기: COZY 밤 달빛 색이 검정이라 툰 셰이더에서 땅이 검게 나왔다. 밤 정도만큼 COZY 달빛을 원래 방식 달빛(색 0.52/0.62/1, 세기 0.8)으로,
  주변광에 (0.10, 0.12, 0.24)를 더한다. 측정(평균 밝기 0~255): 보정 전 18.3(땅 13.5) → 보정 후 27.0(땅 19.0), 원래 방식 24.3(땅 21.8).
- 동굴: AtmosphereController와 같은 판정(발밑 3m 레이어 8). 낮에 동굴이면 COZY 해 ×0.4, 주변광 ×0.6.
- 랜턴: 가방에 랜턴이 있으면 COZY 안개(CZY_FogDepthMultiplier) ×0.38 (62% 걷힘).
- 환경 연출: 맑은 낮 = 나비·낮 벌레·먼지·꽃가루 중 하나, 맑은 밤 = 반딧불이·오로라 2종·유성우 중 하나 (회차·낮밤 해시로 고정),
  안개 밤 = 도깨비불, 그 외(안개 낮·비·폭풍우·눈) = 조용함. COZY가 제 타이머로 바꿔도 다시 맞춘다.
- 함께 고친 것: COZY를 껐다 켜면 원래 방식의 Flat 주변광·Unity 안개·달빛(MoonLight, AtmosphereController가 Start에서 만듦)이 남아 밝기가 2배가 되던 문제
  → 켤 때마다 우리 방향광을 다시 모으고(꺼진 오브젝트 포함), 주변광 모드(Trilight)·안개 켬 여부를 COZY 설정대로 매 프레임 맞춘다.
