# Last Truck 멀티플레이 로비 - 기능과 규칙

팀 전체가 공유하는 문서입니다. 멀티플레이 메뉴(로비)에서 무엇이 되고, 어떤 규칙으로 동작하는지 정리했습니다.
코드 구조가 궁금하면 같은 폴더의 `README_Multiplayer_Code.md`를 보세요.

---

## 1. 기본 방식

- 네트워크: **Photon Fusion 2 / Host 모드**. 방을 만든 사람(방장)의 PC가 서버 역할도 같이 합니다.
- 인원: **1~4명**. 혼자 하고 싶으면 방을 만들고 바로 시작하면 됩니다 (혼자여도 "혼자 있는 방의 방장"이 되는 구조).
- 서버 지역: **kr(한국)으로 고정**. 팀원끼리 서로 다른 지역에 붙으면 방 목록에서 서로의 방이 안 보이기 때문입니다.

## 2. 화면 흐름

```
게임 실행 → [서버 접속 중...] → 방 목록
                                  ├─ 방 만들기 → 대기실(방장)
                                  └─ 방 선택(비밀번호 입력) → 대기실(참가자)
대기실 → 참가자 전원 준비 → 방장이 [게임 시작] → 게임 씬(Demo_01)
```

## 3. 닉네임

- 처음 실행하면 `player` + 4자리 숫자로 자동 생성됩니다. 예: `player0427`
- 방 목록 화면 위쪽 닉네임 칸에서 바꿀 수 있습니다. 직접 바꾼 닉네임은 다음 실행에도 유지됩니다.
- 길이: 2~16자.
- **중복 허용**. 같은 이름이 둘 있어도 문제없습니다. 대기실에서 내 이름 옆에는 `(나)`가 붙습니다.

## 4. 방 목록

- 방 제목, 현재 인원 / 최대 인원, 상태(모집 중 / 게임 중 / 인원 마감), 비공개 방이면 자물쇠 마크가 보입니다.
- **자동 갱신**됩니다. 방이 생기거나, 인원이 바뀌거나, 사라지면 서버가 알려주는 대로 바로 반영됩니다 (몇 초 정도 늦을 수 있음).
- 새로고침 버튼은 없습니다 (Fusion에는 목록을 강제로 다시 받는 기능이 없어서 의미가 없음).
- **게임 중인 방, 인원이 꽉 찬 방은 회색**으로 표시되고 누를 수 없습니다. 목록에서는 들어갈 수 있는 방이 위, 회색 방이 아래에 옵니다.
- **최대 인원 1명인 방은 목록에 표시되지 않습니다** (어차피 아무도 못 들어오니까).
- 목록이 갱신되기 직전에 방이 꽉 차서 입장이 실패하면, 이유를 알려주는 팝업이 뜨고 목록으로 돌아옵니다.

## 5. 방 만들기

| 항목 | 규칙 |
|---|---|
| 방 제목 | 기본값 `닉네임's room`. 비워두고 만들면 기본값을 쓰고, 입력하면 그 제목으로 만듭니다. 최대 24자 |
| 최대 인원 | 1~4명 (기본 4명). `-` / `+` 버튼으로 조절 |
| 공개 설정 | **기본은 비공개(비밀번호 필요)**. 솔로로 하려고 만든 방에 모르는 사람이 들어오지 않게 하기 위함 |
| 비밀번호 | 비공개일 때 **8자리 숫자가 자동으로 채워집니다**. 원하면 바꿀 수 있고(최대 16자), 공개로 바꾸면 입력칸이 회색으로 비활성화됩니다 |

- 비공개인데 비밀번호를 지우고 만들려고 하면 "비밀번호를 입력해야 합니다" 팝업이 뜹니다.
- 비밀번호는 방 목록에 절대 노출되지 않습니다. 대기실에서 **방장에게만** 보이니 친구에게 알려주면 됩니다.

## 6. 방 참가

- 공개 방: 누르면 바로 들어갑니다.
- 비공개 방(자물쇠): 비밀번호 입력 팝업 → 입장.
- 실패했을 때 팝업 메시지:

| 상황 | 메시지 |
|---|---|
| 비밀번호 틀림 | 비밀번호가 올바르지 않습니다. |
| 인원 마감 | 방 인원이 가득 찼습니다. |
| 이미 게임 시작 | 이미 게임이 시작된 방입니다. |
| 방이 사라짐 | 방을 찾을 수 없습니다. |
| 15초 안에 응답 없음 | 응답 시간이 초과되었습니다. |

## 7. 대기실

- 방 제목, `현재 인원 / 최대 인원 · 공개/비공개`, 참가자 목록이 보입니다.
- 참가자 목록: **방장은 왕관 마크**, 준비한 참가자는 **초록색 "준비 완료" 마크**, 아직 준비 안 한 참가자는 "대기 중".
- 참가자에게는 **[준비] 버튼**이 있습니다. 다시 누르면 준비가 취소됩니다.
- 방장에게는 준비 버튼이 없고 **[게임 시작] 버튼**만 보입니다.
  - **방장을 뺀 모든 참가자가 준비해야** 시작 버튼이 눌립니다.
  - 방장 혼자 있으면 바로 시작할 수 있습니다.
  - 버튼이 켜진 직후 누가 준비를 풀거나 새로 들어오면, 누르는 순간 한 번 더 확인해서 시작을 막습니다.

## 8. 게임 시작

- 방장이 시작하면 **모든 참가자가 동시에 게임 씬(Demo_01)으로 이동**합니다. 이동하는 동안은 로딩 화면이 뜹니다.
- 시작하는 순간 방이 **닫힙니다**. 방 목록에서는 "게임 중"(회색)으로 보이고, 게임 도중에는 아무도 들어올 수 없습니다.

## 9. 나가기 / 연결 끊김

- **방장이 나가면 방이 사라지고, 모든 참가자가 방 목록으로 돌아갑니다.** (방장 넘기기 = 재호스팅은 나중에 추가 예정)
  - 다른 참가자가 있을 때 방장이 나가기를 누르면 "정말 나가시겠습니까?" 확인 팝업이 먼저 뜹니다.
  - 남은 참가자에게는 **`호스트 접속 끊김: 방장닉네임`** 팝업이 뜹니다.
  - 대기실에 있을 때뿐 아니라 **게임 중에도 동일**합니다 (게임 씬 → 메뉴의 방 목록으로 이동 후 팝업).
  - 방장이 게임을 강제 종료하거나 인터넷이 끊긴 경우도 같은 메시지로 처리합니다.
- 일반 참가자가 나가면 그 사람만 방 목록으로 돌아가고, 남은 사람들의 목록에서 빠집니다.

## 10. 로딩 화면과 팝업

- 버튼을 눌러 서버 응답을 기다리는 동안(서버 접속, 방 만들기, 방 참가, 나가기, 게임 불러오기)은 **로딩 화면이 전체를 덮어서 다른 조작을 막습니다.**
- 방 만들기 / 방 참가 중에는 로딩 화면에 **[취소]** 버튼이 있습니다.
- **15초** 안에 응답이 없으면 실패로 처리하고 팝업을 띄웁니다.
- 팝업이 여러 개 연달아 생기면 **순서대로 하나씩** 보여줍니다 (서로 덮어쓰지 않음). 팝업은 항상 로딩 화면보다 위에 뜹니다.
- 서버 접속 자체가 실패하면 "다시 시도" 버튼이 있는 팝업이 뜹니다.

## 11. 나중에 할 것 (현재 범위 밖)

- 방장이 나갈 때 다른 사람에게 방장을 넘기는 **재호스팅**
- 게임 중 방장이 튕겨도 판을 이어가는 **Photon 정식 Host Migration** (트럭/자원/맵 동기화가 붙은 뒤)
- 인게임 캐릭터 이동/전투/트럭/제작/맵 생성의 **네트워크 동기화** (현재 브랜치에는 아직 적용 안 됨)
- 인게임 메뉴의 "나가기" 버튼 (코드에는 준비돼 있음: `GameLauncher.Instance.RequestLeaveSession()`)
