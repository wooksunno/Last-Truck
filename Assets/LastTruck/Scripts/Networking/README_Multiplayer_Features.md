# Last Truck 멀티플레이 로비 - 기능과 규칙

팀 전체가 공유하는 문서입니다. 멀티플레이 메뉴(로비)에서 무엇이 되고, 어떤 규칙으로 동작하는지 정리했습니다.
코드 구조가 궁금하면 같은 폴더의 `README_Multiplayer_Code.md`를 보세요.

---

## 1. 기본 방식

- 네트워크: **Photon Fusion 2 / Host 모드**. 방을 만든 사람(방장)의 PC가 서버 역할도 같이 합니다.
- 인원: **1~4명**. 혼자 하고 싶으면 방을 만들고 바로 시작하면 됩니다 (혼자여도 "혼자 있는 방의 방장"이 되는 구조).
- 서버 지역: **kr(한국)으로 고정**. 팀원끼리 서로 다른 지역에 붙으면 방 목록에서 서로의 방이 안 보이기 때문입니다.

## 2. 화면 흐름

```
게임 실행 → [서버 접속 중...] → 방 목록
                                  ├─ 방 만들기 → 대기실(방장)
                                  └─ 방 선택(비밀번호 입력) → 대기실(참가자)
대기실 → 참가자 전원 준비 → 방장이 [게임 시작] → 게임 씬(Demo_01)
```

## 3. 닉네임

- 처음 실행하면 `player` + 4자리 숫자로 자동 생성됩니다. 예: `player0427`
- 방 목록 화면 위쪽 닉네임 칸에서 바꿀 수 있습니다. 직접 바꾼 닉네임은 다음 실행에도 유지됩니다.
- 길이: 2~16자.
- **중복 허용**. 같은 이름이 둘 있어도 문제없습니다. 대기실에서 내 이름 옆에는 `(나)`가 붙습니다.

## 4. 방 목록

- 방 제목, 현재 인원 / 최대 인원, 상태(모집 중 / 게임 중 / 인원 마감), 비공개 방이면 자물쇠 마크가 보입니다.
- **자동 갱신**됩니다. 방이 생기거나, 인원이 바뀌거나, 사라지면 서버가 알려주는 대로 바로 반영됩니다 (몇 초 정도 늦을 수 있음).
- 새로고침 버튼은 없습니다 (Fusion에는 목록을 강제로 다시 받는 기능이 없어서 의미가 없음).
- **게임 중인 방, 인원이 꽉 찬 방은 회색**으로 표시되고 누를 수 없습니다. 목록에서는 들어갈 수 있는 방이 위, 회색 방이 아래에 옵니다.
- **최대 인원 1명인 방은 목록에 표시되지 않습니다** (어차피 아무도 못 들어오니까).
- 목록이 갱신되기 직전에 방이 꽉 차서 입장이 실패하면, 이유를 알려주는 팝업이 뜨고 목록으로 돌아옵니다.

## 5. 방 만들기

| 항목 | 규칙 |
|---|---|
| 방 제목 | 기본값 `닉네임's room`. 비워두고 만들면 기본값을 쓰고, 입력하면 그 제목으로 만듭니다. 최대 24자 |
| 최대 인원 | 1~4명 (기본 4명). `-` / `+` 버튼으로 조절 |
| 공개 설정 | **기본은 비공개(비밀번호 필요)**. 솔로로 하려고 만든 방에 모르는 사람이 들어오지 않게 하기 위함 |
| 비밀번호 | 비공개일 때 **8자리 숫자가 자동으로 채워집니다**. 원하면 바꿀 수 있고(최대 16자), 공개로 바꾸면 입력칸이 회색으로 비활성화됩니다 |

- 비공개인데 비밀번호를 지우고 만들려고 하면 "비밀번호를 입력해야 합니다" 팝업이 뜹니다.
- 비밀번호는 방 목록에 절대 노출되지 않습니다. 대기실에서 **방장에게만** 보이니 친구에게 알려주면 됩니다.

## 6. 방 참가

- 공개 방: 누르면 바로 들어갑니다.
- 비공개 방(자물쇠): 비밀번호 입력 팝업 → 입장.
- 실패했을 때 팝업 메시지:

| 상황 | 메시지 |
|---|---|
| 비밀번호 틀림 | 비밀번호가 올바르지 않습니다. |
| 인원 마감 | 방 인원이 가득 찼습니다. |
| 이미 게임 시작 | 이미 게임이 시작된 방입니다. |
| 방이 사라짐 | 방을 찾을 수 없습니다. |
| 15초 안에 응답 없음 | 응답 시간이 초과되었습니다. |

## 7. 대기실

- 방 제목, `현재 인원 / 최대 인원 · 공개/비공개`, 참가자 목록이 보입니다.
- 참가자 목록: **방장은 왕관 마크**, 준비한 참가자는 **초록색 "준비 완료" 마크**, 아직 준비 안 한 참가자는 "대기 중".
- 참가자에게는 **[준비] 버튼**이 있습니다. 다시 누르면 준비가 취소됩니다.
- 방장에게는 준비 버튼이 없고 **[게임 시작] 버튼**만 보입니다.
  - **방장을 뺀 모든 참가자가 준비해야** 시작 버튼이 눌립니다.
  - 방장 혼자 있으면 바로 시작할 수 있습니다.
  - 버튼이 켜진 직후 누가 준비를 풀거나 새로 들어오면, 누르는 순간 한 번 더 확인해서 시작을 막습니다.

## 7-1. 캐릭터 선택 (대기실)

- 대기실 왼쪽에 **내 캐릭터(초상화 + 이름)**와 **[캐릭터 변경]** 버튼이 있습니다.
- [캐릭터 변경]을 누르면 오버워치/발로란트처럼 **전체 화면 선택 창**이 열립니다.
  - 아래쪽에 모든 캐릭터 **초상화**가 나열됩니다 (한 줄에 8개, 많아지면 스크롤).
  - 초상화를 누르면 **가운데에 큰 초상화, 이름, 설명, 능력치 막대**가 보입니다. (아직 바뀌지 않은 상태 = 미리보기)
  - 가운데 아래 **[변경]**을 눌러야 실제로 바뀝니다. 지금 쓰는 캐릭터를 보고 있으면 버튼이 "사용 중인 캐릭터"로 꺼집니다.
  - **[닫기] 또는 ESC**: 바꾸지 않고 닫기.
- **같은 캐릭터를 여러 명이 골라도 됩니다** (중복 허용).
- 고른 캐릭터는 대기실 참가자 목록에도 **초상화와 이름**으로 보입니다.
- 마지막으로 고른 캐릭터는 저장되어 다음에 방에 들어가도 그대로입니다.
- **게임 시작 버튼을 누른 뒤에는 바꿀 수 없습니다.** 게임 씬에서는 각자 고른 캐릭터로 등장합니다.

## 8. 게임 시작

- 방장이 시작하면 **모든 참가자가 동시에 게임 씬(Demo_01)으로 이동**합니다. 이동하는 동안은 로딩 화면이 뜹니다.
- 시작하는 순간 방이 **닫힙니다**. 방 목록에서는 "게임 중"(회색)으로 보이고, 게임 도중에는 아무도 들어올 수 없습니다.

## 9. 나가기 / 연결 끊김

- **방장이 나가면 방이 사라지고, 모든 참가자가 방 목록으로 돌아갑니다.** (방장 넘기기 = 재호스팅은 나중에 추가 예정)
  - 다른 참가자가 있을 때 방장이 나가기를 누르면 "정말 나가시겠습니까?" 확인 팝업이 먼저 뜹니다.
  - 남은 참가자에게는 **`호스트 접속 끊김: 방장닉네임`** 팝업이 뜹니다.
  - 대기실에 있을 때뿐 아니라 **게임 중에도 동일**합니다 (게임 씬 → 메뉴의 방 목록으로 이동 후 팝업).
  - 방장이 게임을 강제 종료하거나 인터넷이 끊긴 경우도 같은 메시지로 처리합니다.
- 일반 참가자가 나가면 그 사람만 방 목록으로 돌아가고, 남은 사람들의 목록에서 빠집니다.

## 10. 로딩 화면과 팝업

- 버튼을 눌러 서버 응답을 기다리는 동안(서버 접속, 방 만들기, 방 참가, 나가기, 게임 불러오기)은 **로딩 화면이 전체를 덮어서 다른 조작을 막습니다.**
- 방 만들기 / 방 참가 중에는 로딩 화면에 **[취소]** 버튼이 있습니다.
- **15초** 안에 응답이 없으면 실패로 처리하고 팝업을 띄웁니다.
- 팝업이 여러 개 연달아 생기면 **순서대로 하나씩** 보여줍니다 (서로 덮어쓰지 않음). 팝업은 항상 로딩 화면보다 위에 뜹니다.
- 서버 접속 자체가 실패하면 "다시 시도" 버튼이 있는 팝업이 뜹니다.

## 10-1. 인게임 멀티플레이

- **같이 보이는 것**: 모든 플레이어의 **위치, 방향, 달리기/걷기 애니메이션**, 고른 캐릭터 모습.
- **맵**: 방장이 정한 시드로 모두 **같은 맵**(바닥 높이, 구덩이, 자원 위치)이 만들어집니다.
- 캐릭터는 몬스터나 다른 플레이어에게 **밀리지 않습니다** (서로 부딪히면 막히기만 함).
- 카메라, HP바, 인벤토리/제작 UI, 미니맵은 **내 캐릭터 기준**으로 붙습니다.
- **시작 대기**: 모든 참가자가 게임 씬 로딩을 마칠 때까지 "다른 플레이어를 기다리는 중..."이 뜨고 움직일 수 없습니다 (최대 30초, 넘으면 온 사람끼리 시작).
- **낮/밤**: 방장 기준으로 모두 같은 시간이 흐릅니다 (시계, 조명 동일).
- **몬스터**: 방장만 만들고 모두에게 같은 몬스터가 보입니다.
  - 기본적으로 **트럭**을 쫓아갑니다 (거리 제한 없음).
  - **인식 범위(12m)** 안에 플레이어가 들어오면 그 플레이어를 쫓고, 여러 명이면 **가장 가까운 사람**. 15m 밖으로 벗어나거나 죽으면 다시 트럭으로.
  - 사거리(1.5m)에서 멈춰 **공격**합니다 (플레이어 10 / 트럭 10, 1.2초마다). 플레이어를 밀치지 않습니다.
  - **인원이 많을수록 밤 몬스터가 많아집니다** (1인 ×1.0, 2인 ×1.4, 3인 ×1.7, 4인 ×2.0). 동시에 살아 있는 몬스터는 최대 30마리.
  - 수치는 모두 인스펙터에서 바꿀 수 있습니다.
- **전투**
  - 몬스터를 때리면 **빨간색 깜빡임과 데미지 숫자가 모든 사람 화면에** 똑같이 나옵니다.
  - 체력 계산은 방장이 합니다 (누가 때려도 결과가 같음).
  - **팀킬 불가**: 플레이어끼리는 피해를 줄 수 없습니다.
- **사망**: 그 자리에서 사망 애니메이션 → 조작 불가 → **3초 뒤 캐릭터가 사라집니다** (카메라는 그 자리에 멈춤). 관전/부활은 추후.
- **게임 오버**: **모든 플레이어 사망** 또는 **트럭 파괴(내구도 0)** → 모두에게 "게임 오버" 팝업 → [방 목록으로].
- **트럭 인벤토리 (실시간 공유)**: 여러 명이 동시에 트럭 창을 열어 두어도, 누가 넣거나 빼거나 제작하면 **모두의 창이 바로 바뀝니다**.
  - 실제 수량은 방장이 관리합니다. 두 사람이 동시에 같은 아이템을 꺼내도 **있는 만큼만** 나눠지고 복사되지 않습니다.
  - 내 가방이 꽉 차서 못 받은 아이템은 트럭으로 되돌아갑니다. 트럭 기본 지급(테스트 자원)은 방장만 합니다.
- **글자**: 게임 화면의 기본 UI 글자는 한글 폰트(Pretendard)로 바뀌어 작은 글씨도 또렷하게 보입니다.
- **트럭 탑승/운전**
  - 트럭 옆에서 **E** → 먼저 탄 사람이 **운전석(1명)**, 나머지는 **동승석(최대 3명)**. 탄 사람은 캐릭터가 숨고 카메라가 트럭을 따라갑니다.
  - 운전: **W/S** 전진·후진, **A/D** 핸들, **Space** 브레이크, **L** 라이트. 내리기: **E**. 운전석이 비면 동승자는 **F**로 운전석으로 이동.
  - 모든 사람 화면에서 트럭 위치/라이트가 같습니다. 트럭이 파괴되면 운전할 수 없습니다.
  - 트럭에 탄 사람은 몬스터가 노리지 않습니다 (대신 트럭을 공격). 탄 채로 죽으면 트럭 옆으로 내려집니다.
- **무기 연출**: 다른 사람이 든 **활**, 조준 자세, **총알 궤적, 맞은 곳 이펙트, 화염, 날아가는 화살**이 모두에게 보입니다 (피해는 한 번만 계산).
- **특산물 채집**: 고갈/재생성이 모두에게 같이 적용되고, 보너스(희귀 광물 등) 판정은 방장이 합니다. 동시에 마지막 한 번을 캐도 한 명만 받습니다.
  - 개인 가방/파우치/시설 가공/일반 자원 채집은 각자 자기 것이라 따로 처리됩니다.
- **ESC 메뉴**: 창이 열려 있지 않을 때 ESC → "게임 나가기" 확인 → 방 목록으로 (방장이 나가면 게임이 끝남).
- **동료 표시**: 동료 머리 위에 **이름 + HP바**, 미니맵에 **초록 점**(범위 밖이면 테두리에 방향 표시).
- Demo_01에서 바로 Play를 누르면 예전처럼 **싱글플레이**로 동작합니다 (테스트용).

## 11. 나중에 할 것 (현재 범위 밖)

- 방장이 나갈 때 다른 사람에게 방장을 넘기는 **재호스팅**
- 게임 중 방장이 튕겨도 판을 이어가는 **Photon 정식 Host Migration** (트럭/자원/맵 동기화가 붙은 뒤)
- **무기 연출**(들고 있는 무기, 총구 이펙트, 화염, 화살 궤적)을 다른 사람에게 보여주기
- **채집/인벤토리/제작**, **트럭 운전·탑승·수리**의 네트워크 동기화
- 다른 플레이어 머리 위 닉네임/HP바, 미니맵에 동료 표시
- 인게임 메뉴의 "나가기" 버튼 (코드에는 준비돼 있음: `GameLauncher.Instance.RequestLeaveSession()`)
